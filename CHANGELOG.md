## [0.1.2] - 2026-11-14
### Added
- **Hardware Alpha Overlay & `T:01` Sub-Tick Pumping (`reStation.Core`, `reStation.Player`):** Extended [`IPsxGpuBackendHooks`](Dev/src/reStation.Core/Gpu/IPsxGpuBackendHooks.cs) with `RenderUiOverlay(...)`, added `_overlayTex` (`GL_RGBA8`, top-down `uSrcRect=(0,1,1,-1)` flip, cleaned up in `Dispose()`) and centered `4:3`/`16:9` aspect-ratio letterboxing over an opaque black FBO `0` clear in [`OpenGl33RenderBackend.Pipeline.cs`](Dev/src/reStation.Core/Gpu/OpenGl33RenderBackend.Pipeline.cs), and extracted [`ReStationHost.SubTick.cs`](Dev/src/reStation.Player/ReStationHost.SubTick.cs) + [`PsxGpu.Scanout.cs`](Dev/src/reStation.Core/Gpu/PsxGpu.Scanout.cs) (`<= 400 LOC` per file).
- **Native Single-File ZIP `.recomp` Cartridge Support (`reStation.Contracts`, `reStation.Player`):** Synced `reEngine.Core` `v0.1.2` + `reEngine-Setup-v0.1.2-win-x64.exe`, added `ReStationModuleManifest.ResolvedPackagePath` + ZIP `.recomp` manifest detection, added in-memory `ZipArchive`/`MemoryStream` loading in [`ModuleAssemblyLoader`](Dev/src/reStation.Player/ModuleAssemblyLoader.cs), resolved parent `<InstallRoot>\data\rom\` via `RecompPackageReader.ResolveModuleRootDirectory`, and added `Wave3PlaytestAndCartridgeTests` (`129/129` passing tests under `/warnaserror`).

### Changed
- **Overlay Performance & Release Retention (`UiOverlayPresenter`, `build_release.ps1`):** Throttled HUD telemetry re-rasterization in [`UiOverlayPresenter`](Dev/src/reStation.Player/UiOverlayPresenter.cs) to `4 Hz` when the interactive drawer is closed (bypassing per-frame `CaptureRgba` CPU compositing on the live OpenGL path), bumped all `reStation` versions to `0.1.2`, and updated [`build_release.ps1`](Dev/scripts/build_release.ps1) to prune unpacked `Releases\v*` directories past the 2 newest (`v0.1.1`, `v0.1.2` + `Latest` + `.7z`) while retaining historical installers.

### Fixed
- **Crash Past Start Menu (`OpenGL framebuffer incomplete: 0x0000`):** Marshaled `PollSubTickLook()` and `PresentSubTickFrame()` onto SDL/GL owner thread `T:01` via `WaitHandle.WaitAny` pumping (`MarshalToHostThread`, `WaitForFrameOrPumpHostActions`), guarded `GP0(02h)` `ExecuteFillRect` against `SkipPolygonRasterization`, and eliminated sub-tick double-wait / double-present pacing inside [`Program.FrameLoop.cs`](Dev/src/reStation.Player/Program.FrameLoop.cs).
- **Collapsed 3D Geometry Past Start Menu (`GAME.EXE`):** Updated [`PsxGte.Commands.cs`](Dev/src/reStation.Core/Gte/PsxGte.Commands.cs#L70) to pass `lm: false` on `IR1`/`IR2` during `RTPS`/`RTPT` (`lm` applied strictly to `IR3`), invoked `Pgxp.ClearFrame()` inside `PsxGpu.PresentFrame(bool preferLastDrawnOrigin)`, and tracked `LastDrawnX`/`LastDrawnY` backbuffer scanout origins for sub-tick page flips.

## [0.1.1] - 2026-11-14
### Added
- **Additive Engine Seams (`reStation.Contracts`):** Added `IReStationCpuEx` (`SubTickDeadlineCycle`, `Ram`, `NextEventCycle`, `UnwindTargetPc`, `SkipPolygonRasterization`, `BeginSubTickFrame`, `HasCompiledEntry`, `RunSlice`, `TryAdvanceToNextVBlank`), `ISubTickFrameHook` (`SubTickEntryPc`, `MaxSubTickCycles`, `ShouldRunSubTick`, `OnSubTickBegin`, `OnSubTickEnd`, `TryInterceptSubTickCall`, `OnAfterCall`), `IOverlayRecompModule` (`LoadRamAddress`, `ContentSizeBytes`, `ContentSha256Hex`), `IReStationHostEx` (`IsHeadless`, `HasPendingCapture`, `TargetFps`, `IsEnhancedFrameRateEnabled`, `IsModernMouseLookActive`, `MouseSensitivity`, `WaitUntilTimestamp`, `PollSubTickLook`, `PresentSubTickFrame`), and `PsxTelemetrySnapshot.ToHeartbeatMetrics()` while keeping `v0.1.0` ABI interfaces unbroken.
- **Dynamic Overlays & RAM Invalidation (`reStation.Core`):** Removed the 12-module cap in `PsxCpu` and `DiscExeLoader`, added `IOverlayRecompModule` RAM SHA-256 (`0x8019F07C`) overlay disambiguation with cached invalidation via `PsxMemoryBus.NotifyRamWriteRange`, added `PsxCpu.Call` sub-tick interception (`TryInterceptSubTickCall`) and `finally` post-call `OnAfterCall` hooks, and implemented `SkipPolygonRasterization` + `TryAdvanceToNextVBlank`.
- **EOF `"RSTX"` Save Trailer & CLI Router Bridge:** Added EOF-anchored `"RSTX"` trailer framing (`QuickSaveTrailer`, `"BIOS"` + `"OVLY"` chunks) over frozen `"RST1"` schema v1 snapshots (wired into `ReStationHost.SaveQuickSlot` for live `F5` saves), exposed `--preload-media`, `--wait`, and `--version` parity across `CliOptions`, `reStation.Player`, and [`LauncherArgsHelper`](Dev/src/reStation.Launcher/LauncherArgsHelper.cs) (with `[MethodImpl(MethodImplOptions.NoInlining)]` Windows `JobObjectGuard` supervision), and added Wave 2 verification tests (`Wave2CoreSeamTests`, `Wave2CliAndFixtureTests`, `Wave2LauncherAndGlQueueTests`).
- **SDK & `reEngine` Manifest Sync:** Bumped `ReStationEngineInfo.Version` / `Directory.Build.props` / `version.txt` / `Dev\app.manifest.json` to `0.1.1`, synced `reEngine.Core` `v0.1.1` SDK + `reEngine-Setup-v0.1.1-win-x64.exe` bootstrapper, parameterized `<AssemblyName>reStation-Setup-v$(Version)-win-x64</AssemblyName>`, and extended `build_release.ps1` with `--help` + `--version` parity checks plus clean `SharedLibs\reStation\Latest\` purge and `engine.manifest.json` (`"supportedEngineTracks": ["0.1.x"]`) + `README.md`.

### Changed
- **Off-Thread OpenGL Command Queue (`OpenGl33RenderBackend.Queue.cs`):** Marshaled off-thread `SetTextureWindow` (`GP0 E2h`), VRAM transfers, fills, and primitive submissions into a thread-safe FIFO queue drained on the GL context owner thread during `EndFrameAndPresent`, `CaptureRgba`, `PresentRgba`, and `Dispose`.
- **Sub-Tick Isolation & Subheader Guards:** Enforced `IsSubTickRenderGuard` inside `PsxMemoryBus.Write8/16/32` and `WriteIo32` (restricting sub-tick writes to RAM, scratchpad, GP0/GP1, and DMA2/DPCR), called `FramePatch.Reset()` inside `PsxBiosHle.ExecOverlay`, enforced Mode2 raw subheader `0x12` streaming detection in `PsxCdRom.Media` and `Iso9660RawReader`, and wired `HostRuntimeContext.IsEnhancedFrameRateEnabled` (`RecompSettings.FrameRateMode`) into `ReStationHost`.
- **Quartet, Manual Shelf & Strategic Scope Sync (`v0.1.1` Phase 5):** Synchronized `AGENTS.md`, Root Quartet (`README.md`, `FEATURES.md`, `ROADMAP.md`, `CHANGELOG.md`), Manual Shelf (`USER_GUIDE.md`, `OPERATIONS.md`, `ARCHITECTURE.md`, `INTERFACES.md`), locked CLI exit-code / `v1.0.0 win-x64 -> v2.0.0` 10-platform horizon decisions, 5/5 Wave 2 `Sandbox\` Gates `0.1.1-A..E` `PASS` ([`0.1.1.20261114-040030.-.sandbox-verify.md`](Dev/docs/reports/archive/0.1.1.20261114-040030.-.sandbox-verify.md)), and Notion Human Hub / [`task_graph.json`](<PROJECTS_ROOT>/Personal/R&D/Dev/task_graph.json) payloads.

### Fixed
- **Telemetry, Log Format & Exception Resilience:** Fixed `ReStationLogger` Standard 15 timestamps (`yyyy-MM-ddTHH:mm:ss.fffZ [v0.1.1] [PID:<pid>/T:<tid:D2>]`), eliminated triple `[HEARTBEAT]` prefixing and `1/0` denominator noise, recorded real `Stopwatch` timings in `VisibleTestHarness`, emitted single `[WARN] [GL_FALLBACK] reason=headless` in `HostVideoSurface`, caught corrupt `"RST1"` fixture failures cleanly in `FixtureRunnerHost`, and replaced all silent empty `catch` blocks across `Dev\src\` with explicit diagnostics.
