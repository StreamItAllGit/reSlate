# Changelog — reStation

All notable changes to `reStation` will be documented in this file. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Universal SemVer (`MAJOR.MINOR.PATCH`).

## [Unreleased]

## [0.2.8] - 2026-11-16
### Added
- **Per-Game Control Options & `metadataJson` Support (`IModuleInputProfileProvider`, `INativeGameActionHook`, `RecompSettings`, `SlideOverSettingsDrawer`):** Added additive `GameControlOptionChoice` / `GameControlOptionDescriptor` / `ControlOptions` on `IModuleInputProfileProvider` and `ModuleOptions` + `GetOption(...)` on `NativeGameActionContext` (keeping all existing positional constructors and MeadowValley properties backward-compatible), persisted module options under `metadataJson` in `settings.json` (via `MetadataJsonConverter`), updated `F1 -> Controls` to render declared per-game options dynamically alongside live active Modern PC binding summaries, and included `ControlOptions` digests in `UiOverlayPresenter`.
- **`v0.2.8` Regression Suite (`184/184` Passing Under `/warnaserror` — [`Hotfix028RegressionTests.cs`](Dev/src/reStation.Tests/Hotfix028RegressionTests.cs)):** Added 4 regression tests verifying per-game `ControlOptions` + `metadataJson` round-trips and UI dirty tracking, unstretched Hor+ `16:9` pixel proportions + 24-bit `4:3` auto-gating in `PsxGte`/`SoftwareCpuRenderBackend`/`PsxGpu`, mid-tick latched keyboard/mouse edge delivery in `HostInputMapper.BuildLiveInput`, and BIOS `B0:0x09 CloseEvent` reuse + bounded SPU audio stream drain with zero ring-buffer underruns.

### Fixed
- **True Unstretched Hor+ `16:9` Rendering (`PsxGte`, `PsxGpu`, `OpenGl33RenderBackend`, `SoftwareCpuRenderBackend`, `PsxWidescreenGeometry`):** Removed the horizontal `0.75` GTE projection squash (`RTPS`/`RTPT`), added shared `PsxWidescreenGeometry` framing + OpenGL `_wideFbo` / Software `_wideHiBuf` (`428x240` for `320x240` `1:1` square pixels), widened full-screen scissors and untextured fade quads across the `16:9` side wings while keeping 2D HUD/fonts unstretched, preserved idle 30 Hz VBlank frames cleanly, and gated `PsxGpu.EffectiveWidescreen` off automatically during 24-bit MDEC FMVs.
- **Decoupled 60 Hz VBlank Pacing, Mid-Tick Input Latching & Mouse Capture Persistence (`Program`, `Program.FrameLoop`, `Program.MediaGate`, `HostInputMapper`):** Locked `ComputeTargetFps` to `60.0 Hz` outer VBlank cadence while passing Enhanced target FPS cleanly to `ISubTickFrameHook` (skipping redundant post-subtick sleep double-wait), latched SDL keyboard/mouse-down edges across intermediate sub-tick polls (`LatchedKeys`/`LatchedMouseMask`), synced relative mouse acquisition on focused `ModernWasdMouse` gameplay (`WindowInputFocus`), and kept `Esc` bound in `PerGameModern` from dropping mouse capture.
- **Death/Respawn BIOS Event Leaks & Runaway SPU Audio Lag (`PsxBiosHle`, `Program.FrameLoop`, `Sdl3Native`):** Implemented `B0:0x09` `CloseEvent`, closed-slot reuse and live callback deduplication in `B0:0x08` `OpenEvent`, isolated `IntRpTable` heads + SPU output buffer across `ExecOverlay`, and replaced the single-frame `735`-sample read with `DrainSpuAudioToStream` bounded by `BufferedSamples & ~1` and SDL queued-byte capping (`SDL_ClearAudioStream`).
