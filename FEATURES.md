### 4 Live Render Backends (`OpenGL 3.3`, `Vulkan`, `ParallelCpu`, `Software CPU` — `Live` — `v0.3.3`)
- **What it does:** Supports live frame-boundary swaps across `OpenGL 3.3 Core`, hardware `Vulkan` (`VulkanBindings` + `VulkanDeviceContext` dynamic `vulkan-1.dll`, `VK_FORMAT_R16_UINT` `1024x512` `VkImage` + `VulkanPresenter` RGBA swapchain compositing, `[VK_FALLBACK]` revert), zero-allocation deterministic `16px`-band `ParallelCpu` (`ParallelBandRasterizer` using span marshaling and cached parallel options + `ParallelCpuPresenter`, verified `100%` SHA-256 bit-exact with `Software` at `1x`), and `Software CPU`. Preserves canonical `1x` VRAM, `GP0(E6h)` mask bits, `1x`–`8x` PGXP, Hor+ `16:9` wings (`4:3` FMVs), `--require-backend` (`ExitCode = 6`), and live `--doctor` backend probes.

## Standalone Desktop Parity Summary

`reSlate` operates as a **Standalone Desktop Platform Engine** (with zero background daemons or network sockets in Release):
- **Containment, Atomic Persistence & Determinism:** All config (`data\config\settings.json` with auto-migration), save (`"RST1"`/`"RSTX"` `"MCD2"`), Slot 1+2 memory card (`.mcr` under `data\memcards\`, with atomic `.bak-<timestamp>` backup before orphaned block reclaim), `<dataDir>\hdpacks\` texture pack lookups (`ExitCode = 3`), and bring-up profile (`isPureStaticReady`) writes stage atomically (`.tmp -> .bak`), propagate deterministic exit codes (`0..6, 130`), emit `<= 15s` structured telemetry heartbeats (`logs\`), and verify isolated runs under `APP_ISOLATED_TEST=1`.
- **Network Safety Owned by `reEngine`:** `reSlate` opens zero remote sockets in Release (`Debug` loopback binds `127.0.0.1` only when explicitly invoked); feed polling and resumable `.part` transfers live strictly inside `reEngine`.
