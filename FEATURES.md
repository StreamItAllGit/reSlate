## Standalone Desktop Parity Summary

`reSlate` operates as a **Standalone Desktop Platform Engine** (with zero background daemons or network sockets in Release):
- **Containment, Atomic Persistence & Determinism:** All config (`data\config\settings.json` canonicalized in `v0.3.0`), save (`"RST1"`/`"RSTX"`), memory card (`.mcr`), and bring-up profile writes stage atomically (`.tmp -> .bak`), enforce `AppEnvironment.AssertPathContained` (`ExitCode = 3`), propagate deterministic exit codes (`0..6, 130`), emit `<= 15s` structured telemetry heartbeats (`Dev\logs\`), and verify isolated runs under `APP_ISOLATED_TEST=1` and Stage 2 4-Drive Sandbox E2E (`Debug` / `-test.*` only).
- **Network Safety Owned by `reEngine`:** `reSlate` opens zero remote sockets; feed polling and resumable `.part` transfers live strictly inside `reEngine`.
