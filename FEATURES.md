## 3. Planned Feature Cards (`v0.2.0` $\rightarrow$ `v2.0.0`)

### `REST-08` / `REST-09` / `REST-10` — Shared-IR Runtime JIT, `--jit-bringup` & Zero-RWX Cache (`Planned` — `v0.2.0`)
- **Tier 3 Execution Stack:** Unifies `reStation.Compiler` and runtime dynamic translation on one MIPS$\rightarrow$IR frontend (`RecompIrTypes.cs`, `MipsIrLowerer.cs`), extending the unlimited `List<IRecompModule>` registration shipped in `v0.1.1` across dynamic runtime overlays (`MeadowValley: BTN` ships `14` binaries).
- **4 KB + 64B Epoch Safety:** Routes all CPU stores + `DMA2`/`DMA3`/`DMA6` + BIOS `ZeroRam`/`FillRam`/`CopyRam`/`LoadExecutableIntoRam`/`ReadSnapshotState` + `A0:44h` `FlushCache` through `RamPageEpochTable.InvalidateRamRange`, tracks branch + delay-slot page spans across `KUSEG`/`KSEG0`/`KSEG1` mirrors, bounds collectible `DynamicMethod` blocks to `16,384` LRU slots (`RyuJitBlockBackend.cs`), and demotes hot SMC pages (`> 8` writes) to `ThreadedIrBackend.cs` (`Tier3ExecutionCoordinator.cs`).
- **Clean-Room Bring-Up (`JitBringupRecorder.cs`):** Boots verified discs via HLE + RyuJIT under a deterministic `5,644,800`-cycle non-VBlank spin watchdog (**`ExitCode = 5`**, keeping `3` strictly for `STD-03` sandbox violations) and atomically writes zero-retail-byte structural `bringup.profile.json` keyed by `(codeSha256Hex, entryPc, codeSizeBytes, overlayId)` + `indirectJumpTargets` (registered via `/define` at Gate 1).

### `REST-11` / `REST-12` / `REST-13` — Tri-Backend Parity (`Vulkan` + `ParallelCpu`) & Enhancement SDK (`Planned` — `v0.3.0`)
- **Mandatory `v1.0.0` Backend Foundation (`<= 270 LOC` slices):** Splits `GpuCommandQueue.cs` out of `PsxGpu.cs` (`386 LOC`), adds `VulkanBindings.cs`, `VulkanDeviceContext.cs`, `VulkanRenderBackend.cs`, `VulkanRenderBackend.Pipelines.cs`, `ParallelCpuRenderBackend.cs`, and `ParallelBandRasterizer.cs`. Decouples `--headless` from `SDL_VIDEODRIVER=dummy`, teaches `FixtureRunnerHost` to run the selected `--backend`, and fails closed with **`ExitCode = 6`** when `--require-backend` cannot initialize hardware/ICD.
- **Parallel Determinism:** Tiles/row-bands replay binned primitives strictly in GP0 submission order with full worker barriers on `UploadVramRect`/`CopyVramRect`/`TryReadVramRect` or dirty `(TexPage, CLUT)` render-to-texture intersections (`1x` `SHA-256` match against `"software"` across `50` consecutive runs).
- **Enhancement SDK & Drawer Split:** Adds `ISubTickFrameHook : IGameFramePatch` (`SubTickInterpolationSdk.cs`, blocking non-GPU MMIO writes during `InSubTickRender`, locking `PsxSpu` stepping to `60 Hz` VBlanks, and reading `GP0(0xC0)` from `1x` native VRAM) and `<dataDir>\hdpacks\` (`HdTexturePackStore.cs` keyed by `(texPage, clutSha256Hex, rectSha256Hex)`), plus extracts `VideoDrawerTab.cs` from `SlideOverSettingsDrawer.cs`.
