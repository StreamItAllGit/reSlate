## 5. Versioning & Compatibility Notes
- **Backward Compatibility (`reSlate` Partial Rename):** `reStation.Contracts.dll` and `reStation.Core.dll` retain their PE assembly names (`reStation.*` C# namespaces, `AssemblyVersion = 0.3.0.0`) so existing `0.1.x`–`0.3.0` `.recomp` cartridges bind cleanly at runtime, while launcher/player/compiler/decomp/installer outputs use `reSlate.*`, `engineId: "reSlate"`, `engines\reSlate\`, and `SharedLibs\reSlate\v0.3.1\`. `ReStationModuleManifest.Validate` uses bidirectional `reSlate` <-> `reStation` alias matching (`EngineAliasCatalog.AreEquivalent`).
- **Scope (`v0.3.1` Shipped Baseline):** Delivers live shared `reEngine.Host v0.5.0` + `Foundation v0.5.2` integration across 4 active render backends (`OpenGL 3.3`, hardware `Vulkan` `R16UI`, deterministic `16px`-band `ParallelCpu` `100%` SHA-256 bit-exact @ `1x`, and `Software CPU`), `SubTickInterpolationSdk`, `MinimalPngDecoder` + `<dataDir>\hdpacks\` containment (`ExitCode = 3`), audio-safe `Fast-Forward` (`F6` / unbound `Tab`, `xaDrops == 0`) & `ISkipCutsceneHook` (`F7`), `IReStationCpuEx.TryWaitForVBlankCounter`, $O(1)$ `ContainerOffsetBytes` & per-EXE `EntryAddresses` / `"program"` filter, framework-dependent `SharedLibs` Compiler SDK, `suiteId: "reEngine"` installer parity, and `310/310` Release + Debug `/warnaserror` tests (`0` warnings).
